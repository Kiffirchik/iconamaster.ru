## Правила evidence и интерпретации

- Источники цитат — исключительно `title_no_html` и `content_no_html` соответствующего id. HTML-сущности декодированы (включая `&nbsp;`), неразрывные/обычные пробелы и переносы схлопнуты в один пробел, края обрезаны.
- Каждая непустая цитата — точная непрерывная подстрока одного из этих нормализованных полей. Не добавлены многоточия, исправления орфографии или склеенные несмежные фрагменты. Некоторые длинные цитаты размеров нужны, чтобы сохранить контекст обоих размеров и киота.
- Римская запись веков, «Начало», «Конец», «Рубеж» нормализованы только в значении. «Современной работы» / «новописанная» нормализованы в **«Современная»**. «Старинная» без применимой даты оставляет period пустым.
- Даты оклада, венца, вставки, исторического прототипа, стиля и события не датируют сам предмет. Авторская/подписная/единственная работа не означает автоматически современную.
- Назначение — только явно названное применение: фасадная, храмовая, венчальная, аналойная. Сюжет, святой-покровитель, «в рост», складень, парсуна, чудотворность и древняя техника не заменяют назначение. У 9161567 венчальное применение названо прямо; это не вывод из имени Богородицы.
- Обычно используется первый текстовый размер. При ясной связи «икона — киот» размеры разделены; обратный порядок у 8994773 исправлен в значении с сохранением оригинальной цитаты. Единицы не придуманы: **9007323 = «31 × 27»**, без «см». Очевидное «смю» у 8994828 исправлено в значении, но оставлено в evidence.
- Это проверка опоры на текст, а не независимая атрибуция или экспертиза предметов. Даты загрузки, имена файлов, пиксельные размеры изображений, tags и excerpt не использованы как факты о предметах.

### Сохранение описаний

**Описания в public/content/icons.json не изменялись.** Этот результат содержит только метаданные; замену описаний выполняет основной процесс отдельно.

Для существующих 50 не обнаружена потеря предметных дат/размеров в полном свежем `title_no_html/content_no_html` относительно текущих описаний. Есть вставленные цены, дубли заголовков и отличия пробелов/пунктуации; это не новая фактура и не причина заменять очищенный существующий текст.

Два ясных случая более богатого свежего текста: **8994424** (датировка самой иконы в заголовке тела) и **9006482** (добавлены сведения об окладе и киоте). Их допустимо аккуратно добавить к существующему описанию, не теряя прежний текст.

Важное расхождение «короткий источник/фрагмент против существующего описания»: title_no_html нередко не содержит сведений, уже имеющихся в description (например, 8994391 — начало XVII века, реставрация и размер; 8987904 — начало XX века и два размера). Полный content_no_html это подтверждает. Нельзя заменять description коротким заголовком, excerpt или пустым результатом извлечения одного HTML-блока. Для нового id с пустым телом нельзя заимствовать описание одноимённой старой карточки.

Оригинальные шесть записей в `src/data/icons.js` всё ещё имеют описания-заглушки «Уточняется при консультации», тогда как актуальный JSON содержит текст. Шесть сохраняют 24 заглушки прочих паспортных полей. Их старые значения period/type не являются источником evidence. Файл исходных шести не изменялся.
