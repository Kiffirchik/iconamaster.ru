## Результат

В редакторе иконы появились статус и кнопки «Скрыть с сайта» / «Вернуть на сайт».
Скрытые записи остаются редактируемыми. Меняется только `published`, без удаления
изображений, описаний, цен и скидок. В списке редактора скрытые помечены «Скрыта».
Каталог, главная, прямая карточка и навигация учитывают флаг при серверном ответе
и в React. Прямой адрес скрытой иконы возвращает 404 и noindex.

На MTW nginx обходит Apache для XML: после контрольного обнаружения этого поведения
карта переведена на `/content-sitemap.php` с `Cache-Control: no-store`. `robots.txt`
указывает этот адрес, а `/sitemap.xml` является стабильным индексом на PHP-карту.

## Ограничения / последующая работа

- В исходном серверном HTML варианты фильтров остаются сборочными; React обновляет
  их по видимым иконам при запуске. Сами скрытые карточки сервер удаляет полностью.
- Сборочный каталог сохраняет все карточки для возврата. Проверка
  `tests/icon-visibility-readiness.php` запрещает переключение неполных шаблонов.
- Скрытие не является приватным хранением ранее публичных изображений и JSON.
  Поисковые системы и ранее открытые вкладки обновляют свои данные не мгновенно.
