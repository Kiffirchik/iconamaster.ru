# Подробнее об иконе

В Corona откройте карточку иконы и заполните многострочное поле **Подробнее об иконе** под обычным описанием. После сохранения на странице этой иконы появится небольшая кнопка с тем же названием: нажатие раскрывает текст, повторное нажатие сворачивает. Первоначально блок закрыт. В плитках коллекции дополнительный текст не показывается.

Поле содержит обычный текст: переносы строк и пустые строки сохраняются, HTML не выполняется. Пустое поле (или только пробелы) скрывает всю кнопку без пустого блока. Очистите поле и сохраните, чтобы убрать его с сайта.

Ключ данных — `moreDetails`, по умолчанию пустая строка. Старые записи без ключа и `null` поддерживаются. Раскрытие использует нативные `details`/`summary`, доступно с клавиатуры и не требует отдельного запроса или JavaScript. PHP и React выводят один и тот же безопасный текст.

Миграция локальных данных: `node scripts/add-more-details-defaults.mjs`. Публикация через `scripts/deploy-more-details.sh` использует актуальные данные Corona и добавляет только отсутствующий ключ. Скидки, цены, тексты, фотографии и редакторские резервные копии сохраняются. Перед переключением создаются архив и предыдущий корень сайта для отката. Исходники должны быть отправлены в GitHub до публикации.
