# Скидки на иконы

В редакторе Corona откройте карточку иконы и заполните:

- **Цена** — прежняя стоимость, например `100 000 руб.`
- **Скидка (%)** — процент, например `10`.
- **Новая цена (руб.)** — итоговая стоимость, например `90 000`.

Процент и сумма вводятся независимо, автоматического пересчёта нет. Проверьте их соответствие перед сохранением. Новая цена должна быть больше нуля и меньше прежней; процент — больше 0 и меньше 100. Если прежняя стоимость указана «Цена по запросу», сначала задайте числовую цену.

После сохранения каталог и карточка сразу показывают прежнюю цену серым перечёркнутым текстом, красный знак `%` и новую цену. В поисковой разметке товара используется новая стоимость. Кнопка **Скидки** в коллекции работает совместно с периодом и назначением. Повторное нажатие отключает фильтр; «Сбросить» очищает все фильтры.

Чтобы отключить скидку, очистите **Скидка (%)** или укажите `0`. Новая цена перестанет отображаться, даже если остаётся заполненной. Для полного удаления очистите оба поля.

## Модель данных и публикация

`discount` и `newPrice` — необязательные nullable numbers, значения по умолчанию `null`. Старые записи без ключей поддерживаются. Никакие скидки автоматически товарам не назначаются.

Локальные значения по умолчанию: `node scripts/add-discount-defaults.mjs`. На хостинге актуальный `content/*.json` имеет приоритет перед локальными снимками. Публикация `scripts/deploy-discounts.sh` сохраняет полную резервную копию, копирует живые данные на stage под блокировкой редактора, запускает аддитивную миграцию и переключает корень сайта. Существующие цены, тексты, изображения, редакторские резервные копии и авторизация Corona сохраняются.

Перед публикацией: `npm run verify`, приватные PHP-тесты `tests/discounts-php.php`, `tests/live-editor-php.php`, `tests/live-editor-render-check.php`, проверка браузера, commit и push на GitHub.

Для отката восстановить предыдущий корень из `iconamaster.ru.rollback-before-discounts-<release>`, предварительно сохранив актуальные `content/*.json` и `.editor-state`, чтобы не потерять сделанные после публикации изменения. Архив `iconamaster.ru.before-discounts-<release>.tar.gz` — дополнительная резервная копия. Не удалять текущую версию при откате: переименовать её в отдельный каталог для восстановления.
