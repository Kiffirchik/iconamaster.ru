# Скрытие икон

В редакторе `/corona/admin/content.php?kind=icons` откройте икону и нажмите
**Скрыть с сайта**. Статус изменится на **Скрыта**, кнопка — на **Вернуть на сайт**.
Изменение применяется сразу, не удаляет запись и фотографии. Текст скрытой иконы
можно редактировать как обычно. Перед отдельным действием скрытия/возврата сохраните
внесённые в текстовую форму изменения.

Скрытие убирает карточку из каталога, главной и навигации. Прямой адрес отдаёт 404,
а динамический sitemap исключает икону. Это управление публикацией, не секретное
хранилище: существующие публичные URL фотографий и JSON не являются приватными.

Карта сайта: `/content-sitemap.php` (`Cache-Control: no-store`). Она указана в
`robots.txt`; `/sitemap.xml` — стабильный индекс, ссылающийся на неё. На MTW nginx
отдаёт XML до обработки правил Apache, поэтому динамика использует PHP-адрес.
Полный исходный перечень для возврата икон хранится в `.live-templates/sitemap.xml`.

## Данные и дальнейшие публикации

- Единственный флаг: `published` (boolean). Остальные поля не меняются.
- POST защищён существующей авторизацией Corona, CSRF и ревизией записи.
- Атомарная запись и резервная копия JSON выполняются под общей блокировкой.
- При деплое всегда сохранять **все** актуальные `content/*.json` и `.editor-state`.
- Репозиторий хранит полный набор карточек для сборки, включая скрытые на хостинге.
  Не переносить live-флаги `published: false` в сборочный каталог: шаблоны карточек,
  маршруты и исходные записи sitemap нужны для возврата без пересборки.
- Перед переключением нового релиза запускать
  `/usr/local/bin/php52 icon-visibility-readiness.php <stage-root>`.
  Проверка читает актуальный JSON, включая скрытые записи, и запрещает публикацию
  неполного набора шаблонов. Публичный PHP применяет live-флаги при каждом запросе.

## Проверка

`npm run verify` включает тесты клиента и компилятора шаблонов.
На приватной копии `editor-test-*` выполнить `tests/icon-visibility-php.php` под PHP5.2,
затем `scripts/test-icon-visibility-http.sh`: авторизация, CSRF, сохранность всех
полей, ревизии, редактирование скрытой записи, 404, каталог, главная, sitemap и возврат.
Тестовый сервер привязан только к loopback; не публиковать тестовый вход.

## Откат

`scripts/deploy-icon-visibility.sh` создаёт полный архив и rollback-каталог,
проверяет JSON на побайтовое совпадение и только затем переключает сайт.
Перед откатом сохранить текущий сайт и поздние правки редактора отдельно.
Старая версия не поддерживает скрытие: её возврат может снова показать скрытые
иконы, даже если JSON содержит `published: false`.
